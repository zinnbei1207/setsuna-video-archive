# setsuna-video-archive

ライブ・推しカメ等の動画素材を整理するためのアーカイブ台帳とブラウザUIです。

## 主なファイル

- `index.html` — 動画一覧、検索・絞り込み、登録、編集、一括編集、バックアップ
- `data/videos-2025.json` — 2025年台帳
- `data/videos-2026.json` — 2026年台帳
- `data/videos-other.json` — その他のデータ
- `data/timetree-events.json` — 予定照合に使うデータ
- `docs/2026-review-queue.md` — 素材照合・未確定事項・変更の記録

## 台帳とブラウザ編集の違い

GitHub上のJSONファイルが台帳の正本です。ブラウザ画面で追加・編集・削除した内容は、基本的に**そのブラウザの localStorage に保存**されます。ブラウザ操作だけではGitHub上のJSONに自動反映されません。

- 追加データ: `setsuna-added`
- 既存データの編集差分: `setsuna-overrides`
- 画面上で削除した行の非表示情報: `setsuna-deleted`

端末やブラウザを変更する場合、ブラウザのデータを消去する場合は注意してください。画面のバックアップ機能はJSONファイルを書き出しますが、**バックアップファイルを読み込んで復元するUIは現状ありません**。GitHubへの反映や復元作業は別途必要です。

## 識別子と重複の扱い

- `id` は全台帳を通した一意キーではありません。年を跨ぐ重複や、2025年内の重複があるため、`id` だけで動画を同一視しないでください。
- 既存のブラウザ行は原則 `sourceSheet` と `sourceNo` の組合せ（`base|sourceSheet|sourceNo`）で識別します。
- ファイル名だけでは動画の同一性を判定できません。同じ名前でも別の日付・別フォルダー・別の撮影内容の可能性があります。
- 新規取り込み時の画面上の重複候補判定は「グループ・撮影日・ファイル名」の組合せです。**ファイル内容やハッシュを比較した重複確定ではありません**。同一グループ・同日・同名で別フォルダーの動画は手動確認が必要です。

## 撮影日と未確定情報

ファイル名に年を含む日付（例: `2025-03-22`、`VID20260321143045.mp4`）が明示されている場合だけ、新規取り込みフォームの撮影日候補に自動入力します。年のない `0508_live.mp4` や `IMG_1457.MOV` などは推測で補いません。自動入力された日付も撮影日時の証明ではないため、必要に応じて確認してください。

グループ名・会場・日付などは証拠がないまま推測して確定させない方針です。未確定素材の調査状況は `docs/2026-review-queue.md` を参照してください。

## 作業上の注意

1. 修正前に最新の `main`、README、対象ファイル、調査記録を確認する。
2. 元動画を削除・改変しない。台帳も既存の行識別子や参照関係を確認せず再採番しない。
3. 動画の追加は未登録と確認できたものだけを対象にする。撮影日・会場・グループなど不明な項目は保留する。
4. 修正後はデータ整合性を確認し、判断根拠を調査記録に残す。

このREADMEは運用上の注意事項をまとめたもので、アプリの全機能の操作マニュアルではありません。
